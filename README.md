# toDus Desktop

Cliente de escritorio de toDus para Windows. La aplicación se distribuye **únicamente como binario** a través de Releases.

## Descarga

[Última versión](https://github.com/Daro-IR/todus-desktop/releases/latest)

## Actualizaciones

La app comprueba automáticamente `Daro-IR/todus-desktop` al iniciar y desde **Ajustes → Buscar actualizaciones**. Los instaladores y el manifiesto `latest.yml` se publican en Releases.
